# Referencia histórica

`wiki/` contiene las páginas recuperadas del antiguo checkout de la wiki. Se conserva el texto como referencia, sin mantener un submódulo incompleto. El repositorio original, incluidos sus cambios locales, se ha trasladado a `.local/wiki-repository/`.

Estas páginas pueden describir scripts, rutas y comportamientos anteriores. Para el estado vigente consulta el README raíz y `docs/overview/OPERACION_DEMO.md`. No son una segunda fuente canónica de instrucciones.
